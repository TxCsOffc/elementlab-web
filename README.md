# ElementLab — веб-версия

**Сайт:** https://elementlab.uztwix.workers.dev


Интерактивный справочник материалов для микроэлектроники: 118 элементов и соединения,
фазовые диаграммы (с плазмой и сверхтекучестью), 22 состояния вещества, ядро и изотопы,
модели канала транзистора и межсоединений, литография, поиск техпроцесса с проверками реализма
и живые симуляции (молекулярная динамика, уравнение Шрёдингера, оптика литографии, конденсат Бозе–Эйнштейна).

Стек: React + TypeScript + Vite, дизайн-система Astryx, графики recharts, симуляции на canvas.

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
npm run deploy   # сборка и выкладка на Cloudflare Workers
```

Все модели — упрощённые оценки первого порядка; источники и допущения — на странице «Модели и источники».
